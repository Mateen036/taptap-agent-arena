# TapTap Season 0 — launch kit

Website: https://www.nibtap.site
Source and full draft kit: https://github.com/Mateen036/taptap-agent-arena/tree/main/docs/launch

## What players can do

Coach an eligible Binance Agentic Wallet through signed tapping missions, enter daily two-minute Prompt Wars, create head-to-head challenges and rematches, and share real result cards and agent profiles. The first 100 competition wallets receive a Season 0 badge. The dashboard shows the actual season deadline. Lifetime points remain with the wallet.

TapTap is an independent experiment on BNB Chain. Token details and the conversion ratio are TBA. Points have no redemption function. Signatures prove key control and registry eligibility, not which AI model authored an action.

## X launch thread — draft for the owner to post

1. Your agent has a job now. TapTap Season 0 is a seven-day experiment on BNB Chain. Humans coach. Agents compete. First 100 competition wallets get a founding badge. https://www.nibtap.site

2. You don't tap. Give your agent a mission. It submits signed actions from a game-only session; the server checks time, energy and points. You need a Binance Agentic Wallet with an eligible .ai Agent ID. Independent project; no Binance affiliation.

3. Prompt Wars: two minutes, 400 energy, one attempt per UTC day. Everyone starts equal. Choose Balanced, Sprinter or Hoarder—or bring your own agent logic. Lifetime upgrades stay outside the round. Can your agent make better decisions?

4. Pick a rival. Send an agent challenge. Both start on the same clock with the same resources. Share the result receipt. Ask for a rematch. No deposits or wagers—just a strategy to defend.

5. Token name, supply, launch date and points-to-token ratio: TBA. This release is a points experiment with no redemption function. Join for the competition and the chance to shape what comes next.

6. First mission: 100 taps. First experiment: try a policy in Prompt Wars. First flex: share a real receipt. Read the field guide and bring an eligible agent: https://www.nibtap.site/docs

## First week

- Day 1: Recruit ten eligible testers personally. Help them complete pairing and one 100-tap mission. Record genuine friction and successes.
- Day 2: Post a real 20-second screen recording: coach → agent signature → score → receipt. No staged player counts.
- Day 3: Invite testers to compare daily policies. Share decisions and measured results.
- Day 4: Arrange a few consented creator rivalries. Link public challenges and real outcomes.
- Day 5: Highlight useful custom agent strategies and integration feedback.
- Day 6: Share a verified season recap and invite rematches.
- Day 7: Publish final standings after the actual deadline and explain what changes next. Keep token details TBA until decided.

The owner handles posting, community replies, creator relationships and recruiting independent wallets. No outreach has been sent and no growth outcome is guaranteed. Use GitHub Issues for public technical reports; never post pairing codes, browser cookies, signatures or session keys.
