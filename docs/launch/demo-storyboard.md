Hide keys, seeds, pairing codes, private tokens and unneeded wallet identifiers. Pick a short command supported by the current agent connector. ## Edit and proof rules

- Keep the timeline exactly 20 seconds. Hard cuts are fine; label a cut that skips waiting as “wait shortened.” If a run takes longer, show its real elapsed duration rather than implying instant execution.
- The mascot is decorative. Keep it away from score/status values, consent controls and signature details. Never use the mascot art as evidence of an implemented game feature.
- If the connector has no presentable action view, use a redacted genuine server acceptance record with timestamp. Label it “accepted action”; do not design a fictional terminal to stand in for one.
- Use readable captions within mobile safe areas. Keep the official URL visible for the final four seconds. Export an MP4 suitable for social; test caption readability on a phone.
- Save raw recording, redacted accepted-action evidence, deployment URL/version, UTC capture time, real elapsed run time, and tester consent. Compare displayed counters against recorded accepted actions before release.
- If no eligible wallet run succeeds, record the actual blocker for internal feedback and postpone the public demo. Do not publish this storyboard as if it proves the product works.

An end-card for confirmed open recruitment should say “Season 0 open” only after dates and admission are live. Until then retain “Season 0 plan.” All token terms remain TBA, with no guaranteed airdrop or return; include the full disclosure in the accompanying post.
